# NSK Design — Digital

Тема WebCore CMS по `D:/Web/nskdesign.ru/code.html`. Имя папки: `nskdesign-digital`.

## Подключение

1. Загрузить всю папку в `themes/nskdesign-digital/` на сервере.
2. В админке открыть «Темы», обновить список тем и активировать **NSK Design — Digital**.
3. Выбрать тему для своего пользователя. Для анонимных посетителей отдельно установить `SYS_config.default_theme = nskdesign-digital` через настройки сайта.
4. Проверить главную, `/news`, `/about`, `/faq`, `/contacts`, вход и административные страницы.

`theme.php` регистрирует тему штатным сканированием CMS. Изменений ядра и SQL-миграций для темы не требуется. При выборе темы должны существовать установленные стандартные модули CMS.

## Структура

- `pages/default.tpl` — маршрутизация оболочки, SEO, контент и блоки.
- `pages/home.tpl` — лендинг: первый экран, показатели, услуги, направления проектов, этапы, контакты.
- `pages/header.tpl`, `footer.tpl` — навигация и подвал.
- `pages/admin.tpl` — административная оболочка со штатными локальными Bootstrap/jQuery и скриптами CMS.
- `pages/admin-bar.tpl` — вывод фиксированного блока админского меню по имени шаблона, без привязки к ID блока.
- `components/menu_block/admin_menu_display.tpl` — меню администратора без inline-обработчиков jQuery.
- `pages/ajax.tpl` — системные уведомления.
- `messages/normal.tpl` — штатная промежуточная страница сообщений и переходов после входа/сохранения.
- `style/theme.css`, `style/admin.css` — оформление публичных и административных страниц.
- `js/theme.js` — мобильное меню, фильтры, подготовка письма.

Главная определяется штатным объектом `MainPage`. Остальные пользовательские страницы выводят `$module_content`, хлебные крошки и блоки CMS. Административные объекты `::admin::` используют отдельную оболочку и стандартные компонентные шаблоны модулей.

## Макет и данные

Сохранены красный акцент `#D9272E`, графит `#1C1B1F`, светлые поверхности, шрифты Inter / Space Grotesk, 12-колоночная композиция, карточки и структура исходного макета. CSS локальный, Tailwind CDN не используется. На мобильных предусмотрено раскрывающееся меню; фильтры работают с клавиатуры. Анимация отключается при `prefers-reduced-motion`.

Иллюстрации используют исходные внешние URL Googleusercontent из макета; шрифты и Material Symbols — Google Fonts. Доступность этих ресурсов зависит от сети. Картинки в портфолио обозначены как примеры направлений, а не подтверждённые клиентские кейсы. Неподтверждённые гарантии Lighthouse/конверсии/uptime заменены нейтральными подписями. Телефоны взяты из рабочего контекста агентства вместо демонстрационного номера макета.

Форма **открывает почтовую программу** с подготовленным письмом. Она не сохраняет заявку в БД и не имитирует успешную отправку. Прямые ссылки на email, Telegram и WhatsApp доступны независимо от JavaScript. Для серверной отправки требуется отдельное подключение обработчика CMS и проверка фактической доставки.

## Проверка на сервере

- Главная доступна анонимно и администратору, админское меню отображается.
- Внутренние страницы содержат фактический контент модуля и системные сообщения.
- Админские формы и редактор работают с используемыми ими скриптами CMS.
- На 375 / 768 / 1440 px нет горизонтальной прокрутки, меню и фильтры работают.
- Для формы открывается письмо, а не сообщение о фиктивной отправке.

Локальная структурная проверка не заменяет исполнение Smarty/PHP и проверку в браузере целевого сайта.
